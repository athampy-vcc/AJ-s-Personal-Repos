# Establish cloud control applicability and scope

## Description

Identify the workloads, environments, and resource types in scope for the Cloud Security Standard in Greenfield environments, and document control applicability across AWS and Azure.

🌟 Business Goal (SMART)
Define scope and applicability of cloud controls across in-scope workloads in Greenfield and resource types.

✅ Acceptance Criteria (Definition of Done)
Inventory & documentation of:

-Included/excluded services
-AWS vs Azure applicability
-Workloads (prod/non-prod)
-Resource types (IaaS/PaaS)
-Control mapping documentation completed to internal policies/requirements.

🔗 Dependencies
-Cloud inventory (CMDB or discovery tools)
-Application owners / platform teams
-Cloud platform architecture documentation
